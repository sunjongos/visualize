## 💡 Overview

**`visualize`** is a world-class AI Agent visualization engine built on top of **Stitch MCP (Model Context Protocol)** and GitHub's top-trending architecture visualizers (`architecture-diagram-skill`, `mermaid-skill`).

While standard AI tools return walls of markdown text or basic static diagrams, `visualize` generates **cinematic, 1-page interactive web dashboards** featuring:
- **Dark Glassmorphism & Ambient Neon Glow Design Tokens**
- **SVG Animated Pulse Connectors (Visual Flow Diagrams)**
- **Chart.js Executive KPI Dashboards**
- **Neurosymbolic Fact-Locking via Local Knowledge Graphs**
- **4-Tab Multi-Dimensional Inspection Modes**

---

## ⚡ Key Features

- **🏛️ Architecture & Diagram View**: Interactive SVG & Mermaid system diagrams with animated pulse flow connectors.
- **📊 Executive KPI View**: Live dynamic charts (Chart.js / Alpine.js) showing metrics, performance, and trends.
- **🧬 Neurosymbolic Knowledge Graph**: Direct binding with Obsidian `[[Wikilink]]` and SQLite/Neo4j ontology nodes.
- **💎 1-Page Standalone HTML**: Zero build tool dependencies. Single HTML artifact containing all CSS, JS, and SVG assets.
- **📋 1-Click Export**: Instant Markdown/JSON copy and high-res SVG/PDF print actions.

## 📦 Installation & Usage

### 1. Installation into Claude Code / Antigravity IDE

Clone this repository into your agent's skill directory:

```bash
git clone https://github.com/sunjongos/visualize.git .agents/skills/visualize
```

### 2. Slash Commands

Run the command in your agent session:

```bash
/visualize <Topic or Document Path>
```

#### Examples:
```bash
/visualize "Thermodynamic Brain & Triple Self Cognitive Architecture"
/visualize "NDB Namyangju Baek Hospital Management Executive KPIs"
/visualize "C:\Users\USER\Downloads\Cognitive_Report_v9.html"
```

### 3. Standalone Python Generator

```bash
python scripts/generate_visualize.py --source "My Project Architecture" --output dist/visualize_dashboard.html
```
